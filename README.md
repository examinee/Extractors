## 원칙

- 입력은 **최종 페이로드**. 언패킹은 도구 범위 밖이며 각 README에 전제를 명시한다.
- 해석하지 못한 필드도 원본(hex)을 보존해 출력한다.
- 필드 매핑의 근거와 확신도를 문서에 남긴다.
